# Reader2Pdf

[English](README.md)

画面上の PDF リーダーを 1 クリックにつき 1 ページずつ撮影し、1 つの PDF にまとめるツールです。

## 動作環境

- Windows（Windows 11 で動作確認）、Python 3.12 以上
- [uv](https://docs.astral.sh/uv/)

## セットアップ

```sh
uv sync
```

## 使い方

```sh
uv run reader2pdf [--paper A4|B3] [--orientation portrait|landscape] [--delay 秒] [--output パス] [--lang en|ja]
```

1. **範囲を選択する**：画面が静止して暗くなります。ドラッグで撮影範囲を描いてください。縦横比は選んだ用紙の比率に固定されます。
   - `P`：用紙サイズを切り替え（A4 / B3）
   - `O`：向きを切り替え（縦 / 横）
   - `Esc`：キャンセル
2. **撮影する**：撮影範囲が赤枠で示され、その横にプレビューウィンドウが開きます。プレビューウィンドウの外を左クリックするたびに、範囲内が撮影されます。そのため、リーダーの「次ページ」ボタンをクリックすると、今のページを撮影してから次のページへ進みます。
3. **キー操作**（リーダーにフォーカスがあっても使えます）：
   - `D`：直前の撮影を削除（ミスクリック用）
   - `Space`：撮影を終えて PDF を保存

`--output` を指定しない場合、PDF は `output/reader2pdf_YYYYmmdd_HHMMSS.pdf` に保存されます。PDF の各ページは、選んだ用紙の実寸になります。

### オプション

| オプション      | 既定値       | 説明                                                                                            |
| --------------- | ------------ | ----------------------------------------------------------------------------------------------- |
| `--paper`       | `A4`         | 撮影範囲の縦横比に使う用紙。範囲選択中に `P` でも切り替えられます。                              |
| `--orientation` | `portrait`   | 撮影範囲の向き。範囲選択中に `O` でも切り替えられます。                                           |
| `--delay`       | `0`          | クリックしてから撮影するまでの秒数。`0` のときは、リーダーが反応する前のボタンを押した瞬間に撮影します。 |
| `--output`      | 日時から生成 | 保存先の PDF パス。                                                                              |
| `--lang`        | `en`         | UI の言語（`en` / `ja`）。                                                                        |

### 注意

- A4（210×297 mm）と B3（353×500 mm）の縦横比はほぼ同じです（約 1:√2）。用紙の選択は、主に出力 PDF のページの実寸に影響します。
- キー操作はグローバルに効きます。`Space` でリーダーがスクロールしても、そのスクロールは PDF の保存後に起きるので問題ありません。
- プレビューウィンドウは赤枠の外に置いてください。撮影範囲に重なると、撮影画像に写り込みます。

## 開発

```sh
uv run pytest            # テスト
uv run mypy src tests    # 厳格な型チェック
uv run ruff check .      # Lint
uv run ruff format .     # フォーマット
```
